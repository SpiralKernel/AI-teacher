# AI-teacher

面向中国义务教育学生的 AI 数学学习框架。第一阶段聚焦**七年级上册入门**：做题、精确判分、查看解析、记录掌握证据、推荐练习、与 DeepSeek 讨论。

当前是可运行的**本地单学生原型**，尚未制作安卓 APK。代码全部保留在本地，没有创建远程仓库或推送 GitHub。

## 运行

需要 Python 3.11+ 与 [uv](https://docs.astral.sh/uv/)。在项目根目录运行：

```bash
uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8010
```

- 学习页面：http://127.0.0.1:8010
- 交互式接口文档：http://127.0.0.1:8010/docs
- 安卓客户端可使用的 OpenAPI 描述：http://127.0.0.1:8010/openapi.json

不配置 Key 也能完成练习、规则提示、判分、学习记录和掌握度更新。

## DeepSeek 配置

首次需要 AI 时，将 `.env.example` 复制为 `.env`，填写服务端配置；已有 `.env` 时直接编辑，避免覆盖现有配置。

```dotenv
DEEPSEEK_API_KEY=在这里填写自己的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
DATABASE_PATH=data/ai-teacher.sqlite3
AI_TIMEOUT_SECONDS=45
```

修改后重启服务。模型名可通过 DeepSeek 模型列表核实，默认值依官方文档设置。密钥只由后端读取，不下发到前端；`.env`、数据库和备份均被 Git 忽略。

```bash
# 真实 API 测试：查询模型列表，再进行一次简短辅导，会产生少量 API 用量。
uv run python scripts/check_deepseek.py
```

AI 请求只包含当前题目、该知识点的作答摘要和本题最近几轮对话。提交前不发送标准答案；提交后允许参考题库解析。超时、鉴权失败、限流或格式错误时回退到规则提示，并在页面明确标注。AI 可能给出不准确解释，因此不参与判分、修改掌握度或直接发布题目。

## 已有内容

| 需求 | 第一版实现 |
| --- | --- |
| 连接 API | 服务端 DeepSeek 接口、可配置模型、结构化响应校验、错误降级 |
| 学习范围文档 | 4 个单元、12 个起步知识点；学习目标、前置知识、常见误区、版本和来源 |
| 参考题库 | 初始 72 道原创参数化数值题；答案、解析、评分规则、错答规则、难度和校验来源 |
| 学生状态 | 答题记录、独立/提示作答、逐知识点证据、薄弱题型和下一题推荐 |
| 数据自主更新 | 事务保存答题；自动补足未做题；参数题独立数学校验；审计事件和幂等同步 |
| 简单前端 | 中文学习地图、练习、辅导、历史解析、JSON 导出；适应手机宽度 |
| 安卓基础 | 前后端分离的 REST API 与 OpenAPI 描述；后续安卓客户端可复用后端 |

单元包括：有理数、整式的加减、一元一次方程、几何图形初步。这是项目自编的起步范围，**不是某版教材的完整章节覆盖**；例如当前只用部分代表题型验证学习流程，尚未覆盖所有运算变式、推理证明与综合题。具体内容和边界见 [课程范围](docs/curriculum.md)。

## 评价与更新的边界

- 当前仅自动评数值答案。`1/2` 与 `0.5` 精确等价；不执行用户表达式。解题过程评分与拍照识题尚未实现。
- 错答与已知规则匹配时，给出可能的错误模式；无法匹配时标记为“未分类”，不编造诊断。
- 掌握度采用带先验的成功/失败证据估计，不代表考试成绩或经过验证的心理测量。少于 3 次证据显示“证据不足”；提示后正确答案权重降低。同一道题重复作答不重复增加证据。
- 推荐根据前置知识、已有证据和复习间隔决定；可随时手动选知识点。当前题型难度是模板标注，尚无学生群体数据校准。
- 题库只自动扩充经过程序校验的固定模板变式。模板空间耗尽后可能重现旧题，并标记重复证据。自由生成题目需增加审核流程后才能发布。
- 所有种子题均为项目原创，并有数学不变量校验；**尚无教师审定**。正式用于教学前需要教师审核题干、目标匹配与难度。
- 当前使用一个匿名本地学生 `demo`，没有账号认证、学生隔离或家长端。保持本地访问；多人部署前必须先实现认证与授权。

## 数据与维护

SQLite 数据保存在 `data/ai-teacher.sqlite3`，开启外键和 WAL。启动时执行版本迁移与课程同步，不清空答题数据；每次作答后自动为各知识点保留至少 6 道未做题。所有新增题目、作答证据与辅导来源均有审计记录。

```bash
uv run python -m app.manage stats
uv run python -m app.manage sync
uv run python -m app.manage backup
```

备份使用 SQLite 在线备份 API，写入 `data/backups/`。不要用单独复制主数据库文件替代在线备份。浏览器“导出我的学习记录”可下载答题与掌握摘要的 JSON；它不包含 Key，也不是完整数据库备份。

## 验证

```bash
uv run pytest -q
node --check web/app.js
# 启动本地服务后，在已安装 Chrome 的 Linux 环境运行：
uv run python scripts/browser_smoke.py
```

自动化测试使用临时数据库和模拟 AI，不调用付费接口、不修改真实学生数据。覆盖 3,000 套参数题的数学校验、错误模式、数值格式、重复提交、并发写入、提示权重、重启持久化和 API 失败降级。浏览器检查在独立临时数据库启动服务，并通过环境配置禁用 AI Key，避免付费调用和污染学习空间。

## 代码结构

```text
app/
  main.py          HTTP API 和页面入口
  config.py        仅服务端的环境配置
  curriculum.py    学习目标与知识点依赖
  questions.py     参数化题库、独立校验、数值判分
  db.py            数据库、版本迁移、补题、审计
  learning.py      掌握证据、推荐与答题事务
  tutor.py         DeepSeek 和规则辅导
  manage.py        同步、统计与备份 CLI
web/               无需构建的响应式中文界面
tests/             自动化测试
scripts/           浏览器检查与真实 API 检查
docs/              课程边界、架构与后续计划
```
