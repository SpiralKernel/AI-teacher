# AI-teacher

面向中国初中学生的 AI 学习框架。现在提供**初中全科题库、长文阅读、文字/拍照大题评阅、标签选题与细分画像**；原有七年级上册数学地图、原创题练习和已答试卷导入继续保留。

当前是可运行的**本地单学生原型**，尚未制作安卓 APK。代码保存在本地，没有推送 GitHub。

## 运行

需要 Python 3.11+ 与 [uv](https://docs.astral.sh/uv/)。PDF 导入另需 Poppler 的 `pdftoppm`（本机已提供）。

```bash
uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8010
```

- 学习页面：http://127.0.0.1:8010
- 接口文档：http://127.0.0.1:8010/docs
- 后续安卓客户端可复用的接口描述：http://127.0.0.1:8010/openapi.json

不配置 Key 也能在线练习、规则提示、判分和更新画像；识图与拍照题讨论需要支持图片输入的 API。

## DeepSeek 配置

首次将 `.env.example` 复制为 `.env`，填写服务端密钥；已有配置时直接编辑。修改后重启服务。

```dotenv
DEEPSEEK_API_KEY=在这里填写自己的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_VISION_MODEL=deepseek-flash
DATABASE_PATH=data/ai-teacher.sqlite3
AI_TIMEOUT_SECONDS=45
VISION_TIMEOUT_SECONDS=90
```

密钥仅由后端读取，不下发前端；`.env`、数据库、导入页面和备份均被 Git 忽略。当前图片请求使用 [DeepSeek 官方图片输入格式](https://api-docs.deepseek.com/zh-cn/guides/vision/)。

```bash
# 以下脚本调用真实 API，产生少量用量；不写入实际学生记录。
uv run python scripts/check_deepseek.py
uv run python scripts/check_vision.py
```

在线辅导收到当前题目、学习目标、相应知识点/题型摘要与最近对话；提交前不发送题库标准答案。失败时显示规则提示降级。识图在预览后点击“发送至 AI”才会上传归一化图片与课程/题型目录；失败显示原因并允许重试。

全科题库包含语文、数学、英语、物理、化学、生物、历史、地理、道德与法治、科学、信息技术，覆盖初中多个年级。缺少年级/学期标注时不会归为七上。按用户要求不纳入体音美。

原有数学地图保留4个起步单元、12个知识点，**不是某版教材的完整章节覆盖**。[原地图范围](docs/curriculum.md)解释了边界；新的[全科阶段要求文档](docs/junior-curriculum.md)与运行时目录同步。

## 学习阶段与课程依据

在“全科题库”中选择学习阶段、当前单元，可查看这个阶段需要会什么、怎样检查、哪些目标尚待诊断或补题。阶段按科目保存，默认“仅练当前学习范围”，后端同时约束手动选题和AI选题；取消勾选可浏览更广范围。辅导、模型选题和大题评阅会收到当前目标、前置知识与证据摘要，不把后续知识假定为已学。

已核对人教社公开电子教材目录的册次：数学七上（2024）、语文八下（2025）、英语九上（2026）。其它册次依据教育部2022年版课标整理，学期/单元拆分是项目建议，页面明确显示未核对状态；不能视为全部人教版目录已覆盖。科学与理化生可按学校课程安排选用，信息科技九年级为可选复习/项目安排。

题目按来源知识标签建立候选目标映射，不覆盖来源年级或标签，也不证明目标完整覆盖。无练习记录显示“待诊断”，没有候选题显示“待补题”；实验、听说、朗读和项目表现需要实际任务观察。来源指纹与检查范围见[核对清单](app/data/curriculum_sources.json)。

## 全科题库与大题

打开“全科题库”，按科目、知识点/题型、难度与作答方式筛选。搜索会同时匹配题干和标签；“让 AI 按标签选题”会把当前科目的标签目录和作答摘要发送模型，返回的标签必须属于后端目录，再由后端分配题目。

选择题依据来源标准答案判分，多选题比较完整选项集合。阅读组合题和其它主观题保留全文及分题答案，可输入长解答或上传照片；点击“请 AI 检查解答”才发送。AI给出转写、逐步反馈和具体漏洞，用户核对文字与对错后才保存评价。部分正确/无法判断保留记录，不计掌握证据；明确对错的主观题权重0.5，求助后正确进一步降低。同题重复练习不重复计证据。

目前 26,855 道可进入选择/主观作答流程，其中 16,432 道为文字或拍照作答；其它题因缺图、缺答案或格式异常暂不参与练习。这里的“可作答”表示必要字段与材料检查通过，不代表已完成教师审题。

全科画像在题库页面分科查看，学习记录页提供入口，累计练习统计与 JSON 导出包含全科作答。原来的“拍照与试卷”整卷识别仍限定七上数学知识目录；全科题库中的逐题拍照解答已经支持各科。

## 导入已答材料

1. 打开“拍照与试卷”，默认选择已作答材料；可选图片或 PDF，也可在支持的手机浏览器调起摄像头。
2. 每次最多 8 页、8 个文件，单文件 20MB、合计 40MB；PDF 可指定页码范围。上传后先预览，再主动发送 AI 识别。
3. 对照原页逐题核对题干、图形说明、学生答案、参考答案、知识点和题型；看不清或不确定的题选“无法判断”。
4. 确认后生成报告。只有明确选择计入档案的已核对对错题会更新状态；未答、无法判断和空白材料不计错。
5. 可针对一题讨论，也可从薄弱模块进入练习；删除材料同时撤销其掌握证据。

导入证据权重为在线独立练习的一半；核对前求助后答对进一步降低权重。同题跨导入按规范化题干和图形说明去重，无法识别所有改写或不同照片造成的差异。导入题保留在材料中，尚不会自动成为正式随机题库。

## 评价与题库边界

- 在线模板题使用精确数值判分，`1/2` 与 `0.5` 等价，不执行用户表达式。图片答案与过程分析是 AI 建议，由用户核对；不是经过验证的自动阅卷系统。
- AI 新建类型带来源和待审标记；相同规范化名称会复用，目前没有语义同义词合并。可在核对时改选已有题型。
- 画像采用带先验的成功/失败证据估计，不等于考试成绩；少于 3 次有效作答标记“证据不足”。题型会更细，但证据少时不会宣称已掌握。
- 题库仅自动补充经程序校验的原创模板变式；自由生成题和导入材料不会直接发布进题库。挑战题难度为模板标注，尚无学生群体校准，仍需教师审核。
- AI 新类型能建立画像；只有已有模板的类型可直接进入专项刷题。新类型的配套练习需后续补题或审核来源题。
- 已接入的公开题库、许可与筛选规则见 [题库来源](docs/question-sources.md)。来源已有标签不重复调用模型；补充标签带 Luna/AI 来源标记，尚未教师复核。
- 当前仅有匿名本地学生 `demo`，没有多账号、学生隔离或家长端；正式多人部署需先扩展这些能力。

## 数据与维护

SQLite 位于 `data/ai-teacher.sqlite3`，图片位于 `data/imports/`。启动执行版本迁移与同步，保留历史作答；每个知识点补足至少 6 道未做基础/进阶题与 2 道未做挑战题。

公开来源缓存位于 `data/sources/`，学生大题照片位于 `data/bank_answers/`，都不会提交 Git。下载与批量导入可重复执行：

```bash
uv run python scripts/fetch_sources.py
uv run python -m app.manage import-bank --stage junior
```

当前默认导入 CJEval、TAL-SCQ5K 中文初中子集，以及 C-Eval 初中道法 dev/val。源文件、说明与补标签文件有 SHA-256 清单；重复题跳过，来源题内容变化时保留旧快照并退出默认练习。来源更新需运行下载/导入命令，不会静默联网抓取。

```bash
uv run python -m app.manage stats
uv run python -m app.manage sync
uv run python -m app.manage backup
```

备份使用 SQLite 在线备份 API 写入 `data/backups/时间戳.sqlite3`；整卷图片复制到同名 `.assets`，主观解答照片复制到同名 `.answers`。请在没有上传/删除材料时备份。恢复时关闭服务，将数据库放回配置路径，`.assets` 内容恢复到旁边的 `imports/`，`.answers` 恢复到 `bank_answers/`。JSON 导出不含图片或密钥，不能代替完整备份。
