# 公开题库候选与接入计划

核查日期：2026-10-07。项目用于非商用学习。以下为发布方公开资源，尚未批量下载或导入；当前在线题库全部为原创参数模板。

| 来源 | 内容与标注 | 当前用途 |
| --- | --- | --- |
| [TAL-SCQ5K](https://huggingface.co/datasets/math-eval/TAL-SCQ5K) | 数据卡标注 MIT；中文、英文各 5,000 道单选题，含题干、选项、答案、解析、知识点路径与 0—4 难度标签，跨小学至高中竞赛 | 首选候选。先从中文集筛选七上知识范围，再人工检查答案/图形/教材匹配；须增加选择题判分与公式呈现 |
| [TAL-SAQ7K / TAL-SAQ6K](https://github.com/math-eval/aaai2024comp) | 发布仓库声明 MIT；简答题带知识点和难度，但比赛发布数据不含标准答案 | 可研究题型分类，当前不作为可信自动判分题库 |
| [GAOKAO-Bench](https://github.com/OpenLMLab/GAOKAO-Bench) | 高考试题评测数据，含数学、物理等，覆盖客观与主观题；仓库有 Apache-2.0 许可证 | 未来高中扩展候选。具体数据及原卷来源说明需一并保留，不把代码许可当作每份原卷的独立授权证明 |

TAL 竞赛题的难度数字是来源标签，不等于本项目的基础/进阶/挑战分层。应结合目标年级、所需前置知识、教师审题与真实作答反馈重新映射。

## 接入步骤

1. 保留原始题 ID、数据集与版本、下载地址、许可文件、来源原卷、文件哈希和导入时间；禁止覆盖既有历史题快照。
2. 转换题干、选项、标准答案、解析、图形附件、知识点与难度；缺少参考答案或必要图形的题放入待审区。
3. AI 提议知识点/细分题型，优先复用注册表；新类型保留定义、来源与待审状态。
4. 逐题检查教材范围、数学正确性与答案一致性，完成选择题或相应题类判分支持后才能发布到随机练习。
5. 对题干和来源 ID 去重；抽样复核后按难度、题型与学生证据推荐，避免把竞赛标签当作适合所有初一学生的难度。

导入学生已答试卷是个人学习记录流程，不会自动发布为共享题库。当前批量来源适配器与教师审题后台尚未实现。
